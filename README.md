# Açaí da Terra

Landing page estática da Açaí da Terra, feita com HTML, CSS e JavaScript puro.

## Estrutura

```text
index.html
assets/
  css/
    styles.css
  images/
    acai-logo.png
    acai.jpg
    sorvete.jpg
  js/
    main.js
```

O `index.html` é o único ponto de entrada. A navegação usa âncoras para as seções da própria página; os estilos e scripts ficam separados dos arquivos de marcação, e os recursos estáticos são agrupados em `assets/`.

Para executar, abra `index.html` em um navegador ou sirva a raiz do projeto com qualquer servidor HTTP estático.
