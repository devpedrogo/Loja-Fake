## 🥣 Sobre o projeto

A página apresenta a Açaí da Terra, seus diferenciais e opções. A navegação leva direto às seções da própria página, e o layout se adapta a celulares e computadores.

## ✨ O que você vai encontrar

- 🍧 Apresentação da marca e chamadas para ação.
- 🌿 Seções sobre os diferenciais, a marca e o cardápio.
- 📱 Menu adaptado para telas menores.
- 🔐 Janela demonstrativa para entrar ou criar uma conta.

> 💡 **Observação:** o acesso a contas é apenas visual; não há autenticação ou cadastro conectados a um servidor.

## 🛠️ Tecnologias

- 🧱 **HTML** para a estrutura e o conteúdo.
- 🎨 **CSS** para o visual e a responsividade.
- ⚡ **JavaScript** para o menu e as interações.

## 🚀 Como abrir

Não é necessário instalar dependências nem executar um processo de build. 🙌

1. 📂 Abra a pasta do projeto no VS Code.
2. 🌐 Abra `index.html` diretamente no navegador ou use uma extensão como o Live Server.

## 🗂️ Estrutura do projeto

```text
.
├── index.html
└── assets/
    ├── css/
    │   └── styles.css
    ├── images/
    │   ├── acai-logo.png
    │   ├── acai.jpg
    │   └── sorvete.jpg
    └── js/
        └── main.js
```

O `index.html` é o único ponto de entrada. Estilos, scripts e imagens ficam organizados em `assets/`. 🧩
